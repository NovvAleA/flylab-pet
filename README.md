# FlyLab Pet

Лёгкий десктопный питомец для Ubuntu/X11. Насекомое летает поверх окон, реагирует
на экран и выполняет небольшие сценарии. Есть муха, пчела и божья коровка, предметы
в лапах, улей и сценарий 

Для мухи есть сценарий: `кофе → сигарета → сельский сортир`.
Для девочек добавил пчелку с цветочком, которая летает в улей.

## Системные требования

- Ubuntu/Debian с X11;
- Python 3;
- GTK 3 (`python3-gi`, `gir1.2-gtk-3.0`);
- Pillow (`python3-pil`).

Wayland пока не является целевой средой: прозрачные окна и захват экрана могут быть ограничены.

## Установка одной командой

После клонирования:

```bash
./install.sh
```

Скрипт проверит зависимости, при необходимости запустит `apt-get` через `sudo`, а затем установит:

- приложение в `~/.local/share/flylab-pet`;
- ярлык в `~/.local/share/applications`;
- команду `flylab-pet` в `~/.local/bin`.

После публикации на GitHub полная установка будет выглядеть так:

```bash
git clone https://github.com/<USER>/<REPO>.git && cd <REPO> && ./install.sh
```

## Запуск из исходников

```bash
./run.sh
```

Пульт:

```bash
./control.py
```

## Удаление

```bash
./uninstall.sh
```

Настройки в `~/.config/flylab/` при удалении сохраняются.

## Структура

- `app.py` — движение, окна и сценарии;
- `control.py` — GTK-пульт;
- `brain.py` — малая рекуррентная сеть;
- `vision.py` — локальное зрение;
- `appearances.py` и `items.py` — расширяемые реестры;
- `desktop_scene.py` — объекты рабочего стола и сценарий;
- `settings.py` — хранение настроек;
- `assets/` — прозрачные PNG-спрайты.

Проверка синтаксиса:

```bash
python3 -m py_compile *.py
```

## Данные во время работы

- настройки: `~/.config/flylab/desktop-fly.json`;
- PID и журнал: `$XDG_RUNTIME_DIR/flylab-desktop-fly.*`;
- код и спрайты не зависят от имени пользователя или пути к репозиторию.
